> git commit -m "~" main에 아무 커밋이 없으면 브랜치를 생성할 수 없음
> 빈 폴더를 git add . 한다고 해서 추가 되지 않는다.
> 이전 커밋에 수정사항을 추가하려고 한다면 (git add .후에) git commit --amend하면 된다고 함
> git branch 이동 하는법
> (레포에 1개라도 커밋 기록이 있는상태)
> git switch -c <브랜치>   - 브랜치에 입력하길 원하는 이름 생성
